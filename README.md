# Pathfinding Visualizer

An interactive web-based pathfinding visualizer built using HTML, CSS, and JavaScript.

This project demonstrates how graph traversal algorithms work visually on a 20x20 grid.

---

## Features

- Interactive 20x20 grid
- Set custom Start and End nodes
- Add obstacle walls
- Visualize:
  - Breadth First Search (BFS)
  - Depth First Search (DFS)
  - Dijkstra’s Algorithm
- Animated visited nodes
- Highlighted shortest path
- Reset functionality

---

## Algorithms Implemented

### 1. Breadth First Search (BFS)
Explores nodes level by level and guarantees the shortest path in unweighted graphs.

### 2. Depth First Search (DFS)
Explores as deep as possible before backtracking. Does not guarantee shortest path.

### 3. Dijkstra’s Algorithm
Finds the shortest path using distance-based traversal. Works for weighted graphs.
